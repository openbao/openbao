# Securosys Primus HSM

To configure OpenBao auto-unsealing with a Securosys Primus HSM using the PKCS#11 interface, proceed as follows:

1. [Install the Primus PKCS#11 Provider](https://docs.securosys.com/pkcs/Installation/pkcs11_provider_installation/)
    on the same machine as OpenBao or inside the OpenBao container.
    Afterwards, you should have the following:

    - PKCS#11 module path: `/usr/local/primus/lib/libprimusP11.so`
    - Token label: partition name
    - Slot ID: as configured in `primus.cfg`
    - User PIN: PKCS#11 password

1. Continue with the generic [OpenBao PKCS#11 guide](generic.mdx).

The Primus PKCS#11 Provider uses glibc, so in container environments you need to use the `openbao-ubi` image.
