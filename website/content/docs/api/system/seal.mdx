# `/sys/seal`

The `/sys/seal` endpoint seals the OpenBao.

## Seal

This endpoint seals the OpenBao. In HA mode, only an active node can be sealed.
Standby nodes should be restarted to get the same effect.

- **`sudo` required** - This endpoint requires `sudo` capability in
 addition to any path-specific capabilities.

| Method | Path        |
| :----- | :---------- |
| `POST` | `/sys/seal` |

### Sample request

```shell-session
$ curl \
    --header "X-Vault-Token: ..." \
    --request POST \
    http://127.0.0.1:8200/v1/sys/seal
```
